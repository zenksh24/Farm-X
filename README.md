# FarmX 🌿

> **Direct Farmer-to-Buyer Marketplace** — Empowering Tamil Nadu farmers by connecting them directly with consumers for fair pricing and fresh harvests.

---

## ✨ Features

- **Direct Farmer Marketplace:** Browse fresh produce (rice, millets, vegetables, fruits, spices) sourced directly from Tamil Nadu delta and hill farms.
- **District-level Filtering:** Filter produce across districts including Thanjavur, Nilgiris, Salem, Erode, Dindigul, Coimbatore, Madurai, and more.
- **Organic & Certified Produce:** Clear labeling for naturally grown and certified organic crops.
- **Farmer Listing Portal:** Farmers can directly list their harvest with custom pricing, units, and stock quantities.
- **Transparent Cart & Direct Orders:** Transparent pricing directly to the farmer.

---

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/zenksh24/Farm-X.git
cd Farm-X

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production

```bash
npm run build
```
